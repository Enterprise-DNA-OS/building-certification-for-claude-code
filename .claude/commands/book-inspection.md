# book-inspection

Read CLAUDE.md first. Run:

```bash
npm run certify -- book-inspection <job> --stage="Frame" --date=YYYY-MM-DD [--inspector=] --actor="..."
```

Confirm the record and every value with the operator before running. Every write needs --actor with the operator's name. Report the returned row, then run the read that shows the change. Use the stage names from /job-stages so the check counts it.
