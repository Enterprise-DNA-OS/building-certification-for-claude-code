# request-info

Read CLAUDE.md first. Run:

```bash
npm run certify -- request-info <job> --request="..." --due-on=YYYY-MM-DD --actor="..."
```

Confirm the record and every value with the operator before running. Every write needs --actor with the operator's name. Report the returned row, then run the read that shows the change. Then offer /draft-info-request.
